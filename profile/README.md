# Akirama

### Structured mental arithmetic practice, guided by soroban methodology

Akirama helps learners build mental arithmetic skills step by step with
exercises matched to what they have already learned.

[Website](https://akirama.app)

</div>

## Better practice, not random exercises

Mental arithmetic develops through methods learned in a deliberate order.
Akirama turns that curriculum into guided practice: exercises are matched to
the learner's stage, generated reproducibly, and independently checked before
use.

## How Akirama helps

- **The right exercise at the right time** — practice uses only methods
  available at the learner's current stage.
- **A clear learning path** — addition and subtraction progress through the
  Simple, Little Friends, Big Friends, and Family soroban methods.
- **Exercises learners can trust** — every generated chain is independently
  validated.
- **Consistent practice** — versioned rules and deterministic generation make
  exercises reproducible.
- **Explainable by design** — each action can be traced back to the soroban
  method it uses.

## Where we are today

The learning engine currently supports addition and subtraction from one to
four digits across the full implemented soroban progression.

Akirama is in active product development. We are building the learner-facing
practice experience around this foundation, including learner profiles,
sessions, progress tracking, and a dedicated web application. Multiplication
and division are planned for later stages.

## What we believe

- **Pedagogy comes first.** Learning rules guide the technology, not the other
  way around.
- **Correctness is part of the product.** An exercise should be verified, not
  merely generated.
- **Progress should be structured.** Practice should build on methods the
  learner already understands.
- **The experience should stay clear.** Technical complexity belongs behind
  the learning experience.

## About the project

Akirama is a privately developed, proprietary product. Its source code is not
distributed under an open-source license.
